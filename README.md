# 📦 Collection Hub

Aplicación web personal para la gestión y exhibición de colecciones.

## ⚡ Características
- **Conexión directa:** Lee datos en tiempo real desde Google Sheets a través de Apps Script.
- **Vistas dinámicas:** Soporte para vitrinas por slots, grillas con chips de filtro y catálogo general tipo masonry.
- **Privacidad integrada:** Decodificación directa de imágenes almacenadas en Google Drive sin intermediarios.
